Política de Privacidad

Última actualización: 1 de julio de 2026

Resumen

UpFunnel Source Finder es una extensión de navegador que busca fuentes de información relacionadas con el texto que seleccionás. No recopila, almacena ni transmite datos personales a servidores del creador. Todo el procesamiento ocurre directamente en tu navegador.

Qué datos maneja la extensión

  • Texto seleccionado: se usa para buscar fuentes en los proveedores de búsqueda que configures (Serper.dev, DuckDuckGo, Google CSE).
  • API keys: se almacenan localmente en tu navegador (chrome.storage.local). Nunca se envían a ningún servidor del creador.
  • URL de webhook (opcional): si conectás Google Sheets, la extensión envía los resultados de búsqueda a la URL que vos configuraste.

Qué datos NO recopila

  • No recopila información personal (nombre, email, dirección IP).
  • No usa cookies ni trackers.
  • No envía datos a servidores del creador.
  • No vende ni comparte datos con terceros.
  • No accede a tus cuentas, contraseñas ni datos de navegación.

Cómo funcionan las API keys

Las API keys que configures (Serper, OpenAI, Claude, OpenRouter) se guardan exclusivamente en el almacenamiento local de tu navegador. Se envían directamente desde tu navegador a cada proveedor de API cuando realizás una búsqueda o generación de contenido. El creador de la extensión no tiene acceso a estas keys.

Google Sheets (opcional)

Si conectás un Google Sheet mediante webhook (sheet.best, Apps Script), los resultados de búsqueda se envían directamente desde tu navegador a la URL que configuraste. El creador de la extensión no tiene acceso a tu sheet ni a los datos que se guardan allí.

Proveedores externos

La extensión se comunica directamente con estos servicios según tu configuración:

  • Serper.dev — búsqueda web
  • DuckDuckGo — búsqueda web (fallback)
  • Google Custom Search — búsqueda web (fallback, opcional)
  • OpenAI — generación de contenido con IA (opcional)
  • Anthropic (Claude) — generación de contenido con IA (opcional)
  • OpenRouter — generación de contenido con IA (opcional)
  • Google Sheets API — guardado de resultados (opcional, vía webhook)

Cada proveedor tiene su propia política de privacidad. Te recomendamos revisarlas si te interesa.

Almacenamiento local

La extensión usa chrome.storage.local para guardar:

  • Tus API keys
  • Tus preferencias (tema, proveedor preferido)
  • Tus resaltados de texto y fuentes encontradas
  • La URL del webhook de Google Sheets (si configuraste)

Todo esto se almacena solo en tu navegador. Podés borrarlo en cualquier momento desde chrome://extensions/ → Detalles de la extensión → Borrar datos.

Cambios en esta política

Si esta política cambia, se actualizará la fecha en el encabezado. El uso continuo de la extensión después de los cambios constituye aceptación de la nueva política.
